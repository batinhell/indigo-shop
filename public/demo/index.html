Примеры работ

Макеты: list Desktop L / XL / XXL, Filter Bar, ProductCard и gallery_card из файла «💜 Индиго. Сайт». Брейкпоинты из макета — Mobile S 320, Mobile 375, Tablet portrait M 744, Desktop L 1024, Desktop XL 1280, Desktop XXL 2048; колонки каталога (235px) перестраиваются сами, как в трёх вариантах списка.

Что здесь подставлено вместо макета: в gallery_card и карточках товаров картинки — фотографии из хиро-карусели проекта, потому что в макете на их месте серые плейсхолдеры; цены, сроки и скидки в карточках — условные. Названия товаров и все пункты каталога — настоящие, из Figma. Плашка «для кого» пока открывает прежний список аудиторий: нового макета для неё в задаче не было.
